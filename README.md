# Landing Gemini - nueva

Este paquete contiene la landing HTML lista para probar en GitHub Pages.

## Contenido
- `index.html`: página principal de esta landing.
- `assets/`: carpeta preparada para imágenes u otros recursos locales que agregues.
- `.nojekyll`: evita el procesamiento de Jekyll para archivos estáticos.

## Publicar en GitHub Pages
1. Creá un repositorio de GitHub y subí el contenido de esta carpeta (no hace falta subir el ZIP).
2. En el repositorio, abrí **Settings → Pages**.
3. Elegí **Deploy from a branch**, branch `main`, carpeta `/ (root)`, y guardá.
4. Abrí la URL que aparece en Pages.

## Dependencias externas detectadas
La landing conserva sus referencias originales a recursos externos (por ejemplo, Tailwind, Google Fonts e imágenes alojadas en sus URLs originales). Necesitás conexión a internet para que esos recursos carguen. Si alguno de esos recursos deja de estar disponible, descargalo y guardalo en `assets/`, luego actualizá su ruta en `index.html`.

## Importante
Este archivo se empaquetó tal como estaba en el HTML original, sin cambiar textos, precios, testimonios, enlaces de compra ni políticas. Revisá que todo siga vigente antes de usarlo como landing comercial.
